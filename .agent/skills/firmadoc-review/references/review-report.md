# Formato del informe de revision

## 1. Alcance revisado

Describir entrega, commit, rama y criterios de aceptacion.

## 2. Estado real

Inventario de componentes encontrados y ausentes.

## 3. Validaciones ejecutadas

Tabla con comando, objetivo, resultado y evidencia.

## 4. Hallazgos

Para cada hallazgo incluir:

- ID.
- Severidad.
- Componente.
- Evidencia.
- Impacto.
- Criterio incumplido.
- Correccion requerida.

## 5. Comparacion reporte versus repositorio

Marcar cada afirmacion como verificada, parcial, no encontrada o contradicha.

## 6. Pruebas

Mostrar conteo por archivo, total y warnings literales.

## 7. Base de datos

Listar migraciones, tablas, constraints, indices y resultado de reversibilidad.

## 8. Riesgos

Separar riesgos actuales, limitaciones conocidas y funciones fuera de alcance.

## 9. Veredicto

Usar exclusivamente uno de los veredictos definidos en SKILL.md.

## 10. Correcciones requeridas

Lista priorizada y verificable. No aplicar cambios durante la revision.
